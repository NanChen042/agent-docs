## 本章目标

在第一章中，我们实现了一个单一加法工具的 Agent。  
但在实际应用中，Agent 必须面对多维度的复杂需求（例如：“查询北京现在的天气，并根据现在的时间计算距离日落还有几小时”）。

在本章中，我们将手把手带你实现：
1. **多工具动态注册机制**：同时注册计算、天气、时间、系统状态等多个工具；
2. **大模型的工具路由策略（Tool Selection）**：当面对用户指令时，模型是如何在多个工具中做出最优决策的；
3. **多步工具接力调用链（Tool Chaining）**：一个任务需要先调用工具 A 拿到中间结果，再自动将结果传给工具 B 继续处理；
4. **前端多工具可视化渲染**：当一条消息内触发多个工具时，前端如何优雅展示瀑布流式的执行状态。
